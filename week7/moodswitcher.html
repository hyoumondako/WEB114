1. Why is the JavaScript textContent property safer than innerHTML?

textContent only scans the plain text of HTML while innerHTML parses the HTML. If the HTML is from an untrusted source, it may contain malicious scripts.

2. If use an HTML text box on a page and it has an attribute (for example id="text") and a corresponding DOM property (for example, const box = document.getElementById("text"). How do the two elements relate?

The DOM property accesses the HTML "text" attribute and the DOM property will dynamically display the HTML "text" attribute.

3. What would happen to the text box with id="text" if it added this line to the code above:
text.textContent = "Hello!"

The text box's text content will display "Hello!" (with no quotes.)
